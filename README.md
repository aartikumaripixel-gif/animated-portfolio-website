# 🎨 Animated Portfolio Website

An interactive portfolio website inspired by modern creative portfolio designs. This project focuses on animations, smooth scrolling and visually engaging web design.

## ✨ Features

- Modern portfolio design
- Animated typography and visual elements
- Smooth scrolling effects
- Interactive sections
- Custom styling and animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GSAP
- Locomotive Scroll

## 📁 Project Structure

```text
project/
├── index.html
├── style.css
├── loco.css
├── script.js
├── avatar.svg
├── cynthia.webp
├── hudu.png
├── ixperience.png
└── plug.png
```

## 🚀 How to Run

1. Clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
